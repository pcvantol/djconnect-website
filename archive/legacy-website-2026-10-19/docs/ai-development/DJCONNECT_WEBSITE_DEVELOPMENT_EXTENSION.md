# DJConnect Website development extension

`djconnect-website` owns public web presentation, onboarding/support surfaces, public documentation presentation and localized public copy. DJConnect remains the product-authority for cross-component architecture and roadmap.

Use `TECHNICAL_DESIGN.md`, `TESTS.md`, `package.json`, `scripts/`, and the existing website validation/release workflows for local development and validation. Existing `.tde.yml` and Trusted Delivery evidence remain authoritative.
